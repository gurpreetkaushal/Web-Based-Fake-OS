# Web-Based Fake OS 🖥️

## 📌 About the Project

Web-Based Fake OS is a simple interactive operating system interface created using **HTML, CSS and JavaScript**.

The project provides a desktop-like environment where users can interact with different built-in applications and features directly through a web browser.

The main purpose of this project is to understand how HTML, CSS and JavaScript can be combined to create an interactive user interface similar to an operating system.

## ✨ Features

* 🖥️ Desktop-like interface
* 📂 Start Menu
* 🔍 App Search Bar
* 👤 User Profile
* ⚙️ Settings
* 🧮 Calculator
* 📝 Notes
* 🕐 Date and Time
* 🌐 Chrome shortcut
* 💼 LinkedIn shortcut
* 🌄 Wallpaper Change
* 🌓 Light/Dark Mode
* 🔋 Taskbar and system information
* 🔌 Power option

## 🧮 Calculator

The calculator supports basic arithmetic operations:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Decimal values
* Clear operation

## 📝 Notes

The Notes application allows the user to enter a note title and save the note through the interface.

## 🕐 Date and Time

The system displays the current date and time and updates the time automatically.

## ⚙️ Settings

The Settings section provides options for:

* Light/Dark mode
* Changing the desktop wallpaper

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript


## ▶️ How to Run

1. Download or clone this repository.
2. Keep the HTML, CSS, JavaScript and image files in the correct locations.
3. Open `index.html` in a web browser.
4. Interact with the different applications available on the desktop.
